# data/

Local datasets and recordings. **Contents are git-ignored** — never commit audio, video, or model files.

- `raw/` — original recordings and downloaded datasets (e.g. GuitarSet), unmodified.
- `processed/` — derived data (resampled audio, cached features, annotations converted to our formats).

Generated transcription outputs (MIDI, MusicXML, PDFs) go in `outputs/`, which is also git-ignored.
